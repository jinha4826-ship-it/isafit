# 이사핏 (ISAFIT)

집을 고르기 전에, 내 물건과 생활이 그 공간에 맞는지 미리 검증하는 **이사 의사결정 서비스**입니다.
아파트 자동 검색 → 평면도 자동 확보 → 가구 배치 → 공간 적합성 분석(여유 공간·문·동선) → 이사 의사결정 리포트.

- 라이브: https://jinha4826-ship-it.github.io/isafit/ (캐시 우회 `?v=...`)

## 실행
GitHub Pages에서 `main` 브랜치의 `/(root)`를 배포 대상으로 선택하면 됩니다. 빌드 과정 없이 `index.html` 하나로 작동합니다.

## 기능 (v4 · 2026-11-21) — 화이트 리디자인 · 프롭테크 2모드
### 0. 밝은 화이트 베이스 전면 리디자인
- 어두운 올리브/베이지를 걷어내고 **화이트(`#FFFFFF`) + 연한 쿨그레이 배경(`#F6F8FA`)** 위에 **스카이/틸 블루 포인트(`#0EA5E9` · 진한 버튼 `#0284C7`)** 를 얹었습니다. 텍스트는 고대비 다크 슬레이트(`#191F28`).
- 2D 도면 캔버스도 **화이트 + 연한 모눈(`#EEF3F8`)**, 벽은 슬레이트(`#334155`), 창문은 흰 채널 + 파란 이중선, 콘센트는 앰버 아이콘으로 다시 그려 가독성을 올렸습니다. 카드·패널에는 얕은 그림자를 넣어 정보 위계를 잡았습니다.

### 1. 소비자 모드 — 오늘의집 맞춤 사이즈 동선
- 방마다 **들어가는 최대 폭·깊이(mm)** 를 계산해(가구를 빼고 다시 계산하는 교체 시나리오 포함) `오늘의집에서 들어가는 [가구종류] 찾기 ↗` 링크를 붙입니다. 링크는 `https://ohou.se/store/search?query= 소파 180cm` 형태로, 폭은 10cm 단위로 내림해 검색어에 넣습니다.
- 링크가 나오는 곳: ① 처분·교체 권장 카드 ② 여유 부족(주의) 카드 ③ `새로 살 때 권장 최대 치수 · 맞춤 사이즈 찾기` 방별 섹션(소파·침대·식탁·책상) ④ 가구 탭의 선택 가구 판정 카드(그 가구를 빼면 들어가는 최대 폭).

### 2. 소비자 모드 — 이사·사다리차 준비 요약 카드
- 리포트 하단에 **사다리차 필요 여부**(엘리베이터 없음 또는 엘리베이터 치수 초과 가구 존재), 배치 가구 수·반입 위험 수·공간 수, 종류별 구성, 체크사항(현관문·엘리베이터·계단·사다리차·방문 폭 부족)을 정리합니다.
- `포장이사 견적 비교 ↗` · `사다리차 비용 비교 ↗` 는 프로젝트 지역을 넣은 네이버 검색으로 연결합니다. 반입 경로 섹션에도 위험 가구가 있으면 같은 비교 링크가 붙습니다.

### 3. 공인중개사 모드 + 요약 리포트 PNG
- 리포트 탭 상단 **`🏢 중개사 모드`** 토글. 켜면 중개사무소명·담당자·연락처·고객 전달 코멘트를 입력할 수 있고 `data.agent`로 `localStorage`에 저장돼 다음 방문에도 유지됩니다.
- 켜져 있으면 리포트 최상단에 **중개사 브리핑 배지 + 담당자 코멘트**가 표시되고, 인쇄 리포트에도 사무소 서명이 들어갑니다.
- **`🖼️ 요약 리포트 이미지(PNG) 저장`**: Canvas로 1080px 폭 한 장짜리 카드를 그립니다 — 단지명·지역·평형, 그대로 유지/조건부 주의/처분·교체/반입 위험 4지표, 반입 경로와 사다리차 판정, 공간별 적합성, 중개사 모드 ON 시 사무소·연락처·코멘트, 각주. 미리보기 다이얼로그에서 저장합니다.
- 저장은 **Web Share API(파일 공유)** 를 먼저 시도하고, 지원하지 않으면 `a[download]`로 내려받습니다(iOS 사파리는 공유 시트에서 '이미지 저장', 미지원 시 길게 눌러 저장).

### 4. 검증
- 헤드리스 Chromium(iPhone 13 390×844 · 데스크톱 1280) 자동 검증: JS 오류 0건, 문서·리포트 가로 오버플로 0, 오늘의집 링크 형식, 사다리차 카드 판정/링크, 중개사 토글·localStorage 유지·배지, PNG 생성(1080×N)·미리보기까지 확인. 재현: `cd work/isafit/test && python3 verify.py`(LD_LIBRARY_PATH에 `.chromelibs` 지정).

## 기능 (v3 · 2026-11-21)
### 0. 반입 경로(현관문·엘리베이터) · 창문·콘센트 · 전체 평면도
- **프로젝트 반입 경로**: 공간 탭 맨 위 `반입 경로` 패널에서 현관문 폭/높이(기본 850×2000mm), 엘리베이터 폭/깊이/높이(기본 1000×1200×2100mm), 엘리베이터 사용 여부, 계단 이용, 사다리차 가능 여부를 저장. 예전 프로젝트는 `entryWidth`를 현관문 폭으로 승계하고 나머지는 기본값으로 안전하게 채웁니다.
- 가구마다 **현관문 → 엘리베이터 → 방문** 순서로 통과 여부를 판정(문틀 여유 50mm). 실패하면 `반입 위험`으로 표시하고 `현관문 폭 부족 — …`, `엘리베이터 깊이 초과 — … · 사다리차 검토` 처럼 어느 경로에서 막히는지 사유를 보여 줍니다. 의사결정 리포트·인쇄 리포트에 `반입 경로` 섹션이 따로 들어갑니다.
- **방별 창문·콘센트**: 벽면 칩(위/아래/왼쪽/오른쪽, 창문은 복수 선택)과 창문 폭을 설정하면 캔버스에 창문은 **파란 이중선**, 콘센트는 **소켓 아이콘**으로 그려집니다. 가구를 고르면 `위쪽 창문을 가릴 수 있어요 — 채광·결로 확인`, `가까운 콘센트까지 2,300mm — 연장선이 필요할 수 있어요` 같은 참고 안내가 함께 나옵니다.
- **전체 평면도 분리**: 방 캔버스에는 그 방에 직접 올린 사진(`r.planImageKey`)만 배경으로 씁니다. 집 전체 평면도는 스테이지의 `전체 평면도 보기` 버튼으로 100~400% 확대 모달에서 봅니다. AI 방 인식이 준 `bbox`(또는 직접 찍은 핀)로 평면도 위에 방 영역이 겹쳐지고, **방을 누르면 그 방으로 바로 이동**합니다. 위치 정보가 없는 방은 모달 하단 방 바에서 고르고 `방 위치 찍기`로 평면도에 한 번 탭해 지정할 수 있습니다.
- **모바일**: 3탭을 동일 폭 그리드로 바꾸고 좁은 화면에서는 라벨을 `공간/가구/리포트`로 줄여 잘림 없음, 시트 하단 바는 `flex-wrap`+`max-width:100%`로 화면 안에 들어오게 수정, 입력창을 16px로 올려 iOS 자동 확대(줌)를 막았습니다.

### 배치 A안 / B안 비교
- 방마다 배치를 두 안으로 저장합니다(`items` 현재 안 + `altItems` 다른 안 + `activePlan`). 헤더의 `A안/B안` 칩으로 전환하고 `A→B 복사`(현재 안을 반대 안으로 복제, 새 id)로 기존 배치를 그대로 복제한 뒤 가구 몇 개만 옮겨 볼 수 있습니다.
- `A안 vs B안 비교`는 가구 수·배치 가능/여유 부족/반입 위험/배치 불가·문 여닫이 걸림·창문 가림·가장 큰 빈 바닥을 2열로 비교하고 `A안이 더 유리해요 — 배치 불가 1개 감소, 문 걸림 2건 감소`처럼 요약합니다. 한쪽이 비어 있으면 복제를 안내합니다.
- 백업 JSON/불러오기는 `altItems`·`activePlan`을 그대로 담고, `normalize()`가 없는 프로젝트에 빈 B안과 `activePlan:'A'`를 채웁니다.

## 기능 (v2 · 2026-11-21)
### 1. 한국 표준 가구 1탭 등록
- 내 가구 보관함/가구 배치 탭에서 프리셋 13종을 한 번 눌러 등록·배치: 퀸(1500×2000)·킹(1600×2050)·슈퍼싱글(1100×2000) 침대, 3인(2000×900)·4인(2400×950) 소파, 양문형(912×920)·김치(910×900) 냉장고, 4인(1400×800)·6인(1800×850) 식탁, 책상(1200×600), 6단 책장(800×300), 드럼세탁기(600×650), 옷장·행거(1200×600)
- 가구 종류별 **실사용 필수 여유 공간(mm)** 자동 연결: 냉장고 700, 식탁 사방 600, 침대 양옆·발끝 500, 옷장·세탁기·책상·소파 앞 600. 가구별로 직접 수정 가능.

### 2. 문 여닫힘·운반 경로 + 여유 공간 검사
- 공간마다 **방문 폭(기본 800mm)**, **벽면(위/아래/왼/오른쪽)**, **위치**, **안/밖 여닫이**, **경첩 방향**을 설정하고 캔버스에 문틈과 여닫이 반경(호)을 표시. 프로젝트마다 **현관 폭(기본 900mm)**.
- 가구를 선택하면 본체(실선) + **필수 여유 공간(점선 반투명)**이 함께 표시되고, 다음 4가지를 판정합니다.
  1. 배치 가능(여유 있음)
  2. 방에는 들어가나 실사용 여유 부족 — 문 열림 공간 부족, 의자 공간 부족, 다른 가구가 여유 공간을 막음, **방문 여닫이 간섭**
  3. 운반·문 통과 불가 위험 — 현관문·엘리베이터·방문을 통과할 수 있는 단면이 없음(문틀 여유 50mm 반영)
  4. 방 경계 초과 또는 가구 겹침(배치 불가)
- 4방향 회전(90° 단위), `←50 / →50 / ↑50 / ↓50`·`10mm` 미세 이동 버튼, X·Y 숫자 입력, 크기·여유 공간 직접 수정.

### 3. 이사 의사결정 리포트
- **프로젝트 전체**를 한눈에: 등록 가구 N개 중 그대로 유지 / 조건부 주의 / 처분·교체 / 아직 미배치 수.
- 유지 가능 가구(어느 방에 여유 있게 들어가는지), 주의 가구(사유), **처분·교체 권장(사유 + 권장 치수)**, **새로 살 때 권장 최대 치수**(방별 가장 큰 빈자리 계산, 문 여닫이 영역 제외), 공간별 상세.
- `리포트 인쇄`는 위 종합 리포트 + 방별 도면 이미지·판정표를 새 창에 깔끔하게 인쇄합니다.

### 4. 도면 비율·축척
- 배경 도면은 **원본 비율 유지(contain)**로 표시해 찌그러지지 않습니다.
- **축척 보정(2점)**: 도면에서 실제 길이를 아는 두 점을 찍고 mm를 입력하면 방 크기·축척이 자동 보정됩니다.

### 5. 모바일 탭 UI · IndexedDB 저장
- 상세 화면이 **상단 캔버스 + 하단 3탭(공간·도면 / 가구 배치 / 의사결정 리포트)** 구조. `<=820px`에서 캔버스는 상단 고정, 패널은 탭으로 전환.
- 공간 추가는 `prompt()` 대신 인라인 폼.
- `planImage`(base64)는 **IndexedDB(`isafit-db`)** 에 분리 저장하고 `localStorage`에는 메타데이터만 저장(5MB 초과 문제 해결). 기존 `localStorage`의 `planImage`는 첫 로드에서 자동 마이그레이션. 백업/불러오기 JSON에는 도면 이미지도 함께 담깁니다.

### 그 외(기존)
- 아파트 단지 자동 검색(국토교통부 공동주택 단지 목록), 평면도 후보 6장 + AI 방·치수 인식(Gemini Vision), 평면도 직접 업로드, JSON 백업/불러오기, 로그인·서버 불필요.

## 사용 시 참고
- 캔버스에서 가구를 누르면 오른쪽(모바일은 아래) 패널에서 위치·크기·여유 공간을 조정할 수 있습니다.
- 판정 기준은 입력한 치수입니다. AI 인식 결과는 공간 목록에서 바로 수정하세요.
- 문 위치를 옮기려면 `문 위치` 슬라이더를, 여닫이 방향은 `안으로/밖으로`, 경첩은 `왼쪽/오른쪽`을 누릅니다.

## 주의 및 한계
오늘의집·네이버 링크는 제휴가 아닌 일반 검색·상품 탐색 링크이며, 실제 판매·견적 조건은 링크에서 확인해야 합니다. 사다리차 필요 판정은 입력한 현관문·엘리베이터 치수와 가구 단면만 보므로 5층·계단 회전·주차 동선 같은 현장 조건은 포함하지 않습니다.
문은 공간마다 1개, 가구는 직사각형 외곽 기준입니다. 벽 두께·기둥·창문·엘리베이터 크기·계단 회전 반경·분해 운반 가능성은 판정하지 않습니다. PDF 도면 업로드와 여러 후보 주택 간 비교는 지원하지 않습니다. **치수는 실제 도면·현장에서 다시 확인**해 주세요.

## API (Cloudflare Worker `isafit-apartment-api`)

앱은 `https://isafit-apartment-api.cba4826.workers.dev` 하나만 호출합니다(주소는 `index.html` 상수로 고정, 사용자 설정 없음).

| 엔드포인트 | 설명 |
|---|---|
| `GET /?q=푸르지오&region=경남 김해시` | 국토교통부 단지 목록 검색(시·도 단위 캐시) |
| `GET /floorplan-search?apt=부원역푸르지오&pyeong=84㎡&area=경상남도 김해시 부원동` | 평면도 후보 이미지 6장. 검색어는 `"단지명" 지역 평형 평면도`로 만들고 1시간 캐시 |
| `GET /image-proxy?url=...` | 외부 이미지 CORS 프록시(`format=json`이면 data URL) |
| `POST /analyze-floorplan` | `{ imageBase64 \| imageUrl, mimeType, aptName }` → `{ hasExplicitDimensions, summary, rooms:[{name,w,d,estimated}], image:{dataUrl} }` |

분석은 같은 계정의 `maeum-bingsan-ai` Worker `/analyze-floorplan`(v10, Gemini Vision)이 수행하고, 이 Worker는 **Service binding `AI_WORKER`** 로 호출합니다. (같은 계정 Worker를 HTTP로 부르면 Cloudflare `1042` 오류가 납니다.)

### Worker secrets
| 이름 | 용도 |
|---|---|
| `DATA_GO_KR_SERVICE_KEY` | 국토교통부 단지 목록 API |
| `GOOGLE_SEARCH_API_KEY`, `GOOGLE_CSE_ID` | Google Programmable Search(이미지) — 현재 403, 아래 참고 |
| `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | 네이버 개발자센터 검색 API(기존 발급자만, 2027-06-30 종료) |
| `NCP_API_KEY_ID`, `NCP_API_KEY` | NAVER API HUB(NCP) 자격증명 |
| `AI_ANALYZE_URL` (선택) | 분석 엔드포인트 재정의 |

`/floorplan-search`는 설정된 자격증명을 **네이버 개발자센터 → NCP → Google → Bing → DuckDuckGo** 순으로 시도하고, 모두 실패하면 오류를 반환합니다.

### 이미지 검색 제공자 현황 (2026-11-21 실측)
- **네이버 개발자센터 검색 API**: 2026-07-31부터 신규 신청 불가(공지 developers.naver.com/notice/article/32530). 대안은 NCP NAVER API HUB이며 **가입·실명인증·카드 등록이 필요**(검색 API는 무료, 일 25,000회).
- **Google Custom Search JSON API**: 2026-01-20부터 신규 고객 종료. 신규 프로젝트는 `403 This project does not have the access to Custom Search JSON API`가 계속되며 2027-01-01 전면 종료 예정.
- 따라서 지금은 **키가 필요 없는 Bing 이미지 + DuckDuckGo 폴백**으로 동작합니다(비공식, 차단될 수 있음). 품질·안정성을 높이려면 NCP(네이버) 또는 Serper 같은 API 키를 secrets에 넣으면 코드 수정 없이 자동 전환됩니다.
