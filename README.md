# 이사핏 (ISAFIT)

내 가구가 후보 집의 공간에 들어가는지 이사 전에 확인하는 정적 웹앱 MVP입니다.

## 실행
GitHub Pages에서 `main` 브랜치의 `/(root)`를 배포 대상으로 선택하면 됩니다. 빌드 과정 없이 `index.html` 하나로 작동합니다.

## 기능
- 이사 프로젝트 생성 및 지역/이사일/메모 기록
- 프로젝트별 공간 추가 및 치수(mm) 입력
- 가구 보관함에 가구 종류와 가로·세로·높이 등록
- 2D 공간 캔버스에 가구 배치, 드래그 이동, 90도 회전
- 가구끼리 겹침 및 방 경계 초과 검사
- 공간별 비교 기초 기능, 인쇄 리포트
- JSON 백업 내보내기/불러오기
- 브라우저 localStorage 저장, 로그인/서버 불필요

## 주의 및 한계
현재 검사는 입력한 방 경계와 가구 직사각형 외곽 치수만 비교합니다. 문·창문·벽 두께·기둥·콘센트·운반 경로, PDF 도면 자동 판독, 여러 후보 주택 간 종합 비교는 아직 지원하지 않습니다. 브라우저 데이터 삭제 또는 기기 변경 시 데이터가 사라질 수 있으므로 백업을 권장합니다. 실제 치수와 현장 조건을 별도로 확인해야 하며, 결과는 참고용입니다.

## 기술
HTML, CSS, Vanilla JavaScript, Canvas 2D, localStorage.
